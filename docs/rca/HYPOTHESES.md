# Hypotheses and falsification record

All commands refer to `python experiments/sdpa_rca/repro_sdpa.py`; each condition runs in a fresh interpreter. Full arguments, UTC, run ID, fixture/source hashes, exact environment and process exit code are in the [experiment index](../../eval/rca/gfx1151-rocm7141/experiment-manifest.json). `A`, `B`, and `A′` refer to the images-only states defined in [the report](SDPA_ROOT_CAUSE.md).

| Hypothesis | Prediction and minimal falsification experiment | Executed evidence supporting it | Contradicting evidence / uncertainty | Status |
|---|---|---|---|---|
| H1: automatically selected SDPA implementation fails on this Windows gfx1151 stack | DEFAULT fails; MATH passes on identical fixture. Falsify by clean default repetitions passing with original images. | Original BF16+bias DEFAULT observes efficient; scalar no-mask DEFAULT observes flash. Both leave HIP error 1. Three efficient repeats fail in A/A′. `--backend MATH` passes. | FLASH+bias and cuDNN are unsupported, not actual failures. Supported B routes pass. Scope is this exact assembled wheel pair. | CONFIRMED |
| H2: AOTriton/HIP binary or version integration mismatch | Native components/image contract disagree; changing only matching image data repairs launch. Falsify by invariant-controlled images A/B leaving failure unchanged. | Actual wheel bytes and loaded DLL hashes match. Runtime header 0.12.50/05f26c2d; images 0.13/6e00ef3e. Old source reads loose AKS2, package has ZIPs. 0.12 payload alone gives correct output and real module load; restore original gives null launch. All five DLLs and package/driver identities fixed. | A/B does not isolate one GPU instruction; 0.12 payload has fe12b77d signature, not an identical Git SHA to the runtime. No claim of HIP binary ABI corruption. | CONFIRMED for AOTriton runtime/image assembly |
| H3: PyTorch dispatch or argument contract chooses an incompatible configuration | Force valid backends and inspect actual operators; if dispatch/arguments themselves are the primary defect, same operators/inputs should still fail after image replacement. | Source bridge stores unchecked AOTriton error; SDPA returns while HIP last error is 1. This propagates an invalid result. Capability checks can say fused is usable before loading its image. | Same forced operators and exact inputs pass in B, so a separate tensor-argument or selector defect is not needed. No targeted PyTorch error-check patch was compiled. | SUPPORTED for unchecked error propagation; independent argument defect remains OPEN |
| H4: shape/dtype/stride/bias/head dimension uniquely triggers failure | Vary one dimension at a time, masks and dtypes; falsify a SAM/BF16/bias-specific cause with scalar no-mask FLASH or FP32 efficient. | Alignment and masks affect route eligibility: D=1+bias falls to math; efficient requires D divisible by 8. | `[1,1,1,1]` no-mask FLASH fails; BF16/FP16/FP32, none/bias/bool, causal, noncontiguous all fail when a fused path runs. B passes them. Shape is a selector influence, not the root assembly defect. | REJECTED as a unique-input cause |
| H5: HIP runtime/driver/code-object compatibility causes launch failure | With fixed driver/HIP, replace only images. A healthy module load and correct output contradict a generally unusable runtime/driver. `--operation copy_only` is a clean control. | Original trace records hipErrorInvalidValue. | A has no SDPA module load and attempts a null function; B's valid module load/launch succeeds on the exact same DLL/driver. Copy-only and MATH pass. This does not certify all unrelated HIP functionality or drivers. | REJECTED as the necessary primary cause here |
| H6: SAM/CLIP caller constructs invalid SDPA inputs | Remove caller completely: CPU-seeded standalone Q/K/V, no model imports, no mask, one element. | Original model failure occurs in SAM. | Torch-only venv reproduces with no model, HF, Transformers or Triton installed. Public forced FLASH accepts the scalar; identical input passes in B. Existing model/weights are hash verified and unchanged. | REJECTED |
| H7: an earlier asynchronous GPU failure is reported by the later copy | Peek before SDPA and immediately after; synchronize; then copy/arithmetic/cast. Falsify a pre-SDPA origin by clean pre-checkpoints and valid copy-only. | All pre-checkpoints are clean; fused SDPA creates HIP error 1 before later operations. Synchronize returns success and preserves the error. | HIP trace identifies a host-side invalid launch, not a successfully launched kernel later failing asynchronously. No preceding custom GPU kernel is required. Delayed error reporting is confirmed; asynchronous device execution is not. | SUPPORTED for delayed propagation; REJECTED for an earlier unrelated asynchronous kernel |
| H8: failure is independent of standalone Python Triton/DASH | Reproduce in fresh exact-stack venv with only mandatory torch packages; inspect loaded modules. Falsify independence if installation/use of Python Triton is required. | Fresh torch-only A reproduces without Python Triton installed/loaded. Decoder native DASH passes in original adapter-protected OCR. Precompiled AOTriton images are a distinct component. | Original OCR venv has triton-windows installed, and torch introspection can import it there; that import alone neither proves causality nor affects the torch-only result. | CONFIRMED |

Executed minimization commands are the [conditions file](../../eval/rca/gfx1151-rocm7141/conditions.json), and deterministic repetitions are the [repetition file](../../eval/rca/gfx1151-rocm7141/repetition-cases.json), passed via `compare_backends.py --cases <file> --output <fresh-directory>`.

A broad nightly upgrade was deliberately unnecessary once the images-only experiment discriminated the hypotheses. The known upstream pin correction is a maintainer fix candidate; a rebuilt official wheel remains untested. Three successful clean repeats establish reliability for the listed seed/configuration, not a probabilistic failure-rate bound.
